Descrição do professor para o trabalho:

"Desenvolva um sistema desktop com o Java Swing. O tema do sistema é livre.

O sistema deverá:

- Possuir integração com banco de dados
- Manipular 4 ou mais tabelas
- Possuir várias telas
- Utilizar o padrão de projeto MVC.
 

1a Etapa

Definir o tema do sistema
Criar os protótipos de tela
Criar o diagrama de classe das entidades do sistema
Criar o diagrama MER com base nas entidades do sistema"

A gente definiu o tema: "Sistema de Material de Construção". As tabelas que existirão no banco (que será local, SQLite) são: cliente, venda, produto, vendedor, item_venda

A partir disso construa, nesse repositório, o código correspondente para sanar as necessidades do projeto. Divida em uma arquitetura simples e clara, sem exageros de pastas, mas mantendo padrão. Use o padrão MVC.

Desenvolva uma tela Hub, que apresentará o programa e dará as opções de tela: Cadastrar Cliente, Cadastrar Produto, Cadastrar Vendedor, Cadastrar Venda, Listar Vendas, Consultar Clientes. Todas as telas devem possuir um botão padrão que permite retornar ao Hub.
